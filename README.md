# 批号效期台账（总仓 + 8 门店）

按药房四条铁律建的批次级库存系统：**入库五要素缺一不进账、出库强制近效期先出（FEFO）、
过期当天锁死谁也解不开、召回一个批号追全连锁去向**。

技术栈：后端 Python + FastAPI + SQLAlchemy + SQLite（WAL）；前端 Vue 3 + Vite，
构建后由后端同源托管，门店浏览器只访问一个网址，不用装任何东西。

## 一、怎么启动（总仓那台老电脑）

前置：只需装一次 **Python 3.10+**（勾选 Add Python to PATH），不需要任何开发环境。

1. 把整个文件夹放到总仓电脑（路径不要有特殊字符即可）。
2. **双击 `start.bat`**，它会一条龙做完：建独立运行环境 → 装依赖 → 首次自动建库播种
   → 起服务 → 自动弹出浏览器页面。
3. 黑窗口里会打印两个地址：
   - 本机：`http://127.0.0.1:8000`
   - 门店：`http://总仓电脑IP:8000`（8 家门店浏览器直接开；首次若打不开，
     在 Windows 防火墙放行 8000 端口的专用网络）。
4. 关服务：直接关黑窗口。数据在 `data/pharma.db`，**定期把 data 文件夹复制一份就是备份**。

辅助工具：
- `重置演示数据.bat`：清空重建标准演示数据（要输 YES 确认）。
- `运行验收自检.bat`：跑 34 项自动化验收（用临时库，不动正式账）。

## 二、种子演示数据

- 15 个药品；总仓 + 8 家门店（中山一路店、人民广场店、解放桥店、滨江大道店、
  学府路店、城东新区店、经开区店、南站枢纽店）。
- 30 个批次，按今天动态计算效期：
  - **已过期锁死**：氯化钠注射液 批号 `20220108A`（前年就该销毁的那板）；
  - **近效期预警（6 个月内）**：批号 `A00320250301`、`A00720250701`；
  - **质检停售**：批号 `A00520250501`（已挂停售单，放行必须填放行单号）；
  - **召回验收样板**：葡萄糖酸钙注射液 批号 **`HG20260418`**，
    收 600 / 销 115（含拆零）/ 现存 425 / 在途 60（总仓→滨江大道店），
    流向：中山一路店、人民广场店、解放桥店。
- 近三个月的入库、整包装/拆零出库、门店调拨（含 1 笔门店→门店、2 笔在途）流水。

## 三、建议的人工验收走法（对应你说的五条）

1. **并发不穿账**：开两个浏览器窗口，出库页都选总仓同一药品，
   数量都填该药品的全部可出库存，同一秒点确认——只有一单成功，另一单被拒；
   台账里该药品库存为 0，不会出现负数。自动化版见自检脚本（12 路并发）。
2. **锁定拦截**：指定批号选 `20220108A`（过期）或 `A00520250501`（停售）出库，
   都被拒，提示原因；不指定批号走自动 FEFO，系统永远不碰这两批。
3. **FEFO 认账**：同一药品故意指定效期更远的批，系统直接判违规并指出该先出的批号。
4. **召回对账**：召回追溯页输 `HG20260418`，逐店对收/销/调/存，
   在途 60 支单列，页面底部平衡式必须为 0，时间线流水可与纸面逐笔对。
5. **月报对账**：月度报表页翻上月（默认即上月），近效期清单、过期未清、停售清单、
   30 批批次流向表齐全；每月 1 号打开看的就是上个月的账。

## 四、关键业务规则实现位置

| 规则 | 实现 |
|---|---|
| 出库事务 + 条件更新 `qty=qty-n WHERE qty>=n`，撞单回滚重算 | `backend/app/services/inventory.py`（`_conditional_consume` / `_retry`） |
| 物理上禁止负库存 | `stock.qty >= 0` CHECK 约束（`models.py`） |
| FEFO 自动选批、跨批拆单逐批留流水 | `_fefo_plan` + `outbound_flow` 表 |
| 过期次日锁死、6 个月近效期标记，全系统唯一口径 | `services/expiry.py` |
| 停售/放行（放行必须挂单据号） | `quality_hold` / `quality_release` |
| 召回逐店收支存、在途逐单、全流水时间线、平衡校验 | `services/recall.py` |
| 月度近效期清单 + 批次流向表（按流水重算，可复账） | `services/reports.py` |
| 拆零独立台账（折合整盒 + 零头分开记） | `split_sale` 表 / 出库 kind=split |
| 数量全部最小包装单位整数 | 全部 qty 字段 INTEGER + 接口层正整数校验 |

## 五、目录结构

```
start.bat                 双击启动（装依赖/建库/起服务/弹页面一条龙）
重置演示数据.bat
运行验收自检.bat
backend/                  FastAPI 后端
  app/
    main.py               入口，同源托管前端
    models.py             11 张表
    services/             inventory（扣减锁定）/ expiry / recall / reports 四模块
    routers/              stock（台账查询）/ ops（业务操作）
    seed.py               演示数据（带账实平衡自检）
  acceptance_test.py      34 项自动验收
  run_server.py           生产启动入口
frontend/                 Vue3 源码（二次开发用）
frontend_dist/            已构建前端，交付即用，无需 npm
data/pharma.db            SQLite 数据库（首次启动自动生成）
```

## 六、二次开发（开发机，可选）

```bash
# 后端
cd backend
python -m venv .venv && .venv\Scripts\activate      # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# 前端（改完 npm run build，产物自动进 frontend_dist/）
cd frontend
npm install
npm run dev      # 开发热更，:5173 代理 /api 到 :8000
npm run build
```
